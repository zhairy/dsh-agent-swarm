# 安装

本插件面向 **DSH 0.2.x**（`>=0.2.0-rc.2 <0.3.0`，推荐 0.2.1-rc.2），已在沙箱中用 0.2.1-rc.2、0.2.1-alpha.4 与 0.2.0-rc.2 完成集成测试。下面的命令以 Linux / macOS 为例；Windows 把 `~/.dsh` 换成 `%USERPROFILE%\.dsh`。

> 从 0.1.7 升级时，第三方插件可能声明了旧的 `peerDependencies`：在 profile 里用
> `dsh plugin --profile <p> allow-version <包名@版本> --dsh-version <DSH 版本> --accept-risk` 为确认可用的插件登记例外；
> 用 pnpm 补丁修改过的插件，升级后要检查补丁是否随新版本失效（`npm run doctor` 会检查 dsh-llm-fallbacks 的百工排除补丁）。

## 1. 备份

```sh
cp -a ~/.dsh ~/.dsh.backup-$(date +%Y%m%d)
```

回退方法见 [升级与回退.md](升级与回退.md)。

## 2. 安装 DSH

```sh
npm i -g @deepseek-ai/dsh@0.2.1-rc.2
dsh --version   # 应输出 0.2.1-rc.2
```

## 3. 安装本插件

任选一种方式，装好后重启 `dsh`：

- **插件市场（dsh-market）**：搜索 `dsh-agent-swarm` 一键安装（市场优先使用 Release 里的预构建包）。
- **预构建包**：
  ```sh
  dsh plugin --profile <profile> add https://github.com/zhairy/dsh-agent-swarm/releases/latest/download/dsh-agent-swarm.tgz
  ```
- **从源码**：
  ```sh
  git clone https://github.com/zhairy/dsh-agent-swarm.git
  cd dsh-agent-swarm
  npm install          # prepare 会构建 lib/
  dsh plugin --profile <profile> add "$(pwd)"
  ```
  链接安装后，改了代码只需重新 `npm run build` 并重启 `dsh`。

推荐新建干净的 profile 避免旧插件干扰：`dsh --profile swarm --from-default-profile web`，看到 Web 地址后按 Ctrl+C 退出即已创建。

## 4. 联网搜索（dsh-web-search-free）

```sh
dsh plugin --profile <profile> add dsh-web-search-free
```

启动 Web 后，在侧栏「插件」→「已安装」→ **web-search-free** 的卡片里填入搜索 API key。本插件不保存这些 key：博闻使用的 `web_search` / `web_fetch` 由它提供后端。

## 5. 模型 provider

在 Web 界面「设置 → 模型」中添加 provider 并填写凭据：

| provider | 凭据引用名 | 用途 |
|---|---|---|
| `qwen-token-plan-cn`（Qwen Token Plan CN） | `QWEN_TOKEN_PLAN_CN_API_KEY` | 订阅额度，它目录里有的模型优先走这里 |
| `opencode-go`（OpenCode Go） | `OPENCODE_GO_API_KEY` | 订阅额度；MiMo、MiniMax-M3、GLM-5.3、Kimi 等 |
| `codex` / `claude`（dsh-plugin-subscriptions） | 订阅登录 | ChatGPT 与 Claude 订阅模型 |
| DeepSeek（`deepseek-official`） | `DEEPSEEK_API_KEY` | 按量 API，各角色链的最终兜底 |

各角色的模型链在「设置 → 百工 Agent」里按你的订阅调整。选择器上的模型遇到额度耗尽等致命失败时，天枢按角色链自动回退，并在 `agents.rootRecoverMs` 后重新尝试所选模型。

### 与 dsh-llm-fallbacks 共存

dsh-llm-fallbacks 的全局回退（`rootChain`）会抢在百工之前处理额度耗尽、限流、认证失败，打乱百工的路由、升级与独立性安排。百工在 `globalThis[Symbol.for('dsh-agent-swarm/managed-agents')]` 登记它管理的会话，dsh-llm-fallbacks 需要读取这份登记并跳过这些会话：

```js
const isSwarmManaged = (agent) => { try { return globalThis[Symbol.for("dsh-agent-swarm/managed-agents")]?.isManaged?.(agent) === true } catch { return false } }
// agent/request-error 开头：if (isSwarmManaged(agent)) return next()
// agent/request 在 const seed = await next() 之后：if (isSwarmManaged(agent)) return seed
```

上游尚未支持时，用 `pnpm patch dsh-llm-fallbacks@<版本>` 在 profile 里加上这三行；`npm run doctor` 会检查补丁是否生效，升级 dsh-llm-fallbacks 后需要重新打。

## 6. ChatGPT Plus 与 Claude Pro 原生客户端（可选）

```sh
dsh plugin --profile <profile> add @deepseek-ai/dsh-subagent-codex
dsh plugin --profile <profile> add @deepseek-ai/dsh-subagent-claude-code
```

- **Codex**：先用 ChatGPT 账号完成 Codex 官方登录（例如 `npx @openai/codex login`）。
- **Claude Code**：沿用本机已有的 Claude Code 登录；非交互的 Agent SDK 用量计入 Claude 订阅额度。

本插件会为它们各建两个实例：`swarm-codex` / `swarm-codex-edit` 和 `swarm-claude-plan` / `swarm-claude-edit`，只有对应 bundle 已安装时才启用。默认只在 `swarm_delegate` 明确传入 `backend: codex/claude` 时使用，每个会话最多 3 次。

## 7. Jev（衡鉴与 jev_* 工具）

在「设置 → 百工 Agent」顶部的「Jev 模型 API Key」卡片里粘贴 key 并保存：它保存在 DSH 凭据存储中（引用名 `TYPESAFE_API_KEY`），不会写入任何配置文件，保存后立即生效；「测试连接」会列出账号可用的 Jev 模型。也可以用环境变量或 systemd 的 `EnvironmentFile` 提供（此时卡片显示「只读」，修改后需重启 DSH）。

不配置也能用：衡鉴只按规则分流，涉及算法改动的任务走「严格路径」（强制验算与审查），衡鉴复评显示为「未执行」，`jev_*` 工具返回 401 与配置提示。插件内嵌了 Jev 工具与技能，不需要再单独安装 jev-mcp。

## 8. 检查

```sh
npm run doctor -- --profile <profile>
```

逐项处理带 ✗ 的项目。doctor 只检查凭据引用**是否存在**，不会读取或打印任何密钥值。

## 9. 使用

```sh
cd <你的项目目录>
dsh --profile <profile> web
```

新建会话选「百工模式」（天枢）。需要把某个专家单独作为主会话使用时，设置 `DSH_SWARM_ROLE_PRESETS=1` 后重启 dsh。使用方法见 [使用.md](使用.md)。

## 卸载

```sh
dsh plugin --profile <profile> remove dsh-agent-swarm
```

卸载不会删除工作区文件，也不会删除账本（`~/.dsh/share/dsh-agent-swarm/ledger`）。
