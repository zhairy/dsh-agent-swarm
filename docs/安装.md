# 安装

v3.4.2 仅支持 DSH **0.2.3-alpha.2**，需要 Node.js **24.22.3（24.x）或 >=26.13.1**。旧 rc.3 宿主应继续使用 v3.4.1，不能通过版本豁免装入此包。

## 安装插件

```bash
dsh plugin --profile web add https://github.com/zhairy/dsh-agent-swarm/releases/download/v3.4.2/dsh-agent-swarm.tgz
```

离线安装时先下载同一发布页的版本化 tgz 和 SHA256SUMS，核验摘要。也可从解包目录使用内容摘要安装器：

```bash
node scripts/install-profile.mjs --tarball ./dsh-agent-swarm-3.4.2.tgz --profile ~/.dsh/profiles/web
```

该安装器只调整插件依赖与必要本地链接；不会安装或升级 DSH、修改模型凭据、迁移 MCP 清单或启停服务。配置已确认后，由外部终端按当前部署方式重启 DSH。

## alpha.2 宿主桥接

alpha.2 的冻结前模型切换与实际执行边界需要本包提供的摘要绑定桥接。先使用 `scripts/apply-alpha2-bridges.mjs --dsh <DSH_NODE_MODULES> --check` 只读核验。若需要应用，必须在外部终端停止目标 DSH 后执行，再检查并启动；不要原地修改正在运行的 Harness。

桥接只接受 manifest 中核验过的精确组件与文件摘要，版本或内容不符会拒绝。完整合同与恢复方式见 [宿主与执行服务](3.4.2-alpha2宿主与独立执行服务.md)。

## 模型与 Jev

在「设置 → 百工 Agent」配置各角色模型链。人工选模优先于自动回退。Jev 可使用 TypeSafe 官方凭据，也可使用当前 DSH 目录中具备对应合同的第三方模型。不要把凭据写入示例配置或项目提交。

补阙默认模型链为空，只有真实失败事件能触发；未配置、权限或见证不足时转人工，不自动选择收费模型。

## 可选执行服务

Python / Node 隔离内核是单独启用的功能，默认不启动。使用 [runtime/README.md](../runtime/README.md) 构建运行镜像并生成用户 service，再由管理员核对后安装。没有 Docker、镜像或可信 scope 时显式不可用，不退回宿主裸执行。

## 第三方插件

此包仅发布 Swarm。DSH SDK、Subscriptions、Notebook、MCP 管理器、OpenCode 设置页等第三方组件应分别安装和维护。Swarm 不以插件依赖更新自动迁移这些组件的配置。

## 可选 provider 与后端

天枢与专家的路由以 DSH 当前供应商目录为准。常见凭据引用名如下；实际引用以该 provider 的设置为准，不能将不同订阅的 Key 混用：

| provider | 示例凭据引用 |
| --- | --- |
| Qwen Token Plan CN | `QWEN_TOKEN_PLAN_CN_API_KEY` |
| OpenCode Go | `OPENCODE_GO_API_KEY` |
| TypeSafe Jev | `TYPESAFE_API_KEY` |

如需原生子智能体后端，分别安装 `@deepseek-ai/dsh-subagent-codex`、`@deepseek-ai/dsh-subagent-claude-code` 并按其官方流程登录；Swarm 只在已安装对应后端、合同与权限均满足时派发，不替代其登录或授权。网页检索可单独安装 `dsh-web-search-free`，其凭据由该插件管理。这些可选包均不在 Swarm 安装包中。

## 检查安装

在插件解包目录运行 `node scripts/doctor.mjs --profile web`（也可 `npm run doctor -- --profile web`），逐项核对宿主、插件、凭据引用与后端。不要用完整诊断日志代替脱敏后的问题描述。升级前保留原插件包和配置；回退时恢复已知兼容版本，不删除会话或重置账本。
