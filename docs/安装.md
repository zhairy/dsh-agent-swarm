# 安装

本插件面向 **DSH 0.2.0-rc.2**（最低 0.1.7-alpha.2），已在沙箱中用 0.2.0-rc.2、0.1.7-rc.2、0.1.7-rc.1 与 0.1.7-alpha.2 完成集成测试。下面的命令以 Windows PowerShell 为例；Linux / macOS 把路径换成对应写法即可（例如 `~/.dsh`）。

> 从 0.1.7 升级到 0.2.0-rc.2 时，第三方插件可能声明了旧的 `peerDependencies`：在 profile 里用
> `dsh plugin --profile <p> allow-version <包名@版本> --dsh-version 0.2.0-rc.2 --accept-risk` 为确认可用的插件登记例外；
> 用 pnpm 补丁修改过的插件，升级后要检查补丁是否随新版本失效（`npm run doctor` 会检查 dsh-llm-fallbacks 的百工排除补丁）。

## 1. 备份

```powershell
Copy-Item -Recurse "$env:USERPROFILE\.dsh" "$env:USERPROFILE\.dsh.backup-$(Get-Date -Format yyyyMMdd)"
```

升级会把 `settings.yaml` 迁移成 `settings.yaml.imported`，旧式预设目录也不再被读取，所以请先备份。回退方法见 [升级与回退.md](升级与回退.md)。

## 2. 升级 DSH

```powershell
npm i -g @deepseek-ai/dsh@0.2.0-rc.2
dsh --version   # 应输出 0.2.0-rc.2
```

升级后需要知道的变化：

- 预设改为 bundle 声明。`~/.dsh/.agent-presets/` 下的旧式预设（vibe-math、rigorquant、ultramath 等）**不再显示**，迁移方法见《升级与回退》。
- 首次启动 `dsh web` 时，`settings.yaml` 中各插件的设置会被导入各自的 profile 配置。当时加载失败的插件会被跳过，其设置留在 `settings.yaml.imported` 中。
- 你 web profile 里的部分第三方插件可能尚未适配 0.1.7。

## 3. 选择 profile（推荐新建）

推荐新建一个干净的 `swarm` profile，避免旧插件干扰：

```powershell
dsh --profile swarm --from-default-profile web
# 看到 Web 地址后按 Ctrl+C 退出，profile 就已创建好
```

如果想装进现有的 `web` profile，把下文所有 `--profile swarm` 换成 `--profile web` 即可。

## 4. 构建并安装本插件

```powershell
git clone https://github.com/<你的 GitHub 用户名>/dsh-agent-swarm.git
cd dsh-agent-swarm
npm install
npm run build
dsh plugin --profile swarm add <本插件目录的绝对路径>
```

`dsh plugin add` 会以链接方式安装本目录。之后改了代码，只需重新 `npm run build` 并重启 `dsh`。

## 5. 联网搜索（dsh-web-search-free）

```powershell
dsh plugin --profile swarm add dsh-web-search-free
```

启动 Web 后，在侧栏「插件」→「已安装」→ **web-search-free** 的卡片里填入你的六个搜索 API key，并拖动调整调用顺序。本插件不保存这些 key：博闻使用的 `web_search` / `web_fetch` 由它提供后端。

## 6. 模型 provider

在 Web 界面「设置 → 模型」中添加以下内置 provider，并填写 API key：

| provider | 凭据引用名 | 用途 |
|---|---|---|
| `qwen-token-plan-cn`（Qwen Token Plan CN） | `QWEN_TOKEN_PLAN_CN_API_KEY` | 首选：它目录里有的模型一律先走这里 |
| `opencode-go`（OpenCode Go） | `OPENCODE_GO_API_KEY` | 备用；MiMo、MiniMax-M3、GLM-5.3、视觉实验模型只在这里有 |
| DeepSeek（`deepseek-official`） | `DEEPSEEK_API_KEY` | 最终兜底 |

主会话模型（天枢）建议在模型选择器中选 `qwen-token-plan-cn / deepseek-v4.1-flash`（评测不低于 V4 Pro，价格约 1/4，且支持图片）。选择器上的模型遇到额度耗尽等致命失败时，天枢会按 `qwen → opencode-go → deepseek` 的链自动回退。

### 与 dsh-llm-fallbacks 共存

dsh-llm-fallbacks 的全局回退（`rootChain`）会抢在百工之前处理额度耗尽、限流、认证失败，把天枢和专家切到它自己的链上，打乱百工的路由、升级与独立性安排。百工在 `globalThis[Symbol.for('dsh-agent-swarm/managed-agents')]` 登记它管理的会话（百工预设的根会话，以及百工委派的专家子会话），dsh-llm-fallbacks 需要读取这份登记并跳过这些会话：

```js
const isSwarmManaged = (agent) => { try { return globalThis[Symbol.for("dsh-agent-swarm/managed-agents")]?.isManaged?.(agent) === true } catch { return false } }
// agent/request-error 开头：if (isSwarmManaged(agent)) return next()
// agent/request 在 const seed = await next() 之后：if (isSwarmManaged(agent)) return seed
```

上游尚未支持时，用 `pnpm patch dsh-llm-fallbacks@<版本>` 在 profile 里加上这三行。其他模式和其他插件的子会话不受影响，仍走全局回退。`npm run doctor` 会检查补丁是否生效；dshmarket 升级 dsh-llm-fallbacks 后补丁会失效，需要重新打。

## 7. ChatGPT Plus 与 Claude Pro（可选的升级通道）

这两个订阅**不是 API key**，只能通过官方原生客户端使用：

```powershell
dsh plugin --profile swarm add @deepseek-ai/dsh-subagent-codex
dsh plugin --profile swarm add @deepseek-ai/dsh-subagent-claude-code
```

- **Codex**：先用 ChatGPT 账号完成 Codex 官方登录（例如 `npx @openai/codex login`）。
- **Claude Code**：沿用你本机已有的 Claude Code 登录。按 Anthropic 的说明，非交互的 Agent SDK 用量会计入 Claude 订阅额度，请在账号设置中确认相关额度策略。

本插件会自动为它们各建两个实例：`swarm-codex` / `swarm-codex-edit` 和 `swarm-claude-plan` / `swarm-claude-edit`。只有在对应 bundle 已安装时，这些实例才会启用。默认只在 `swarm_delegate` 明确传入 `backend: codex/claude` 时使用，每个会话最多 3 次。

## 8. Jev（衡鉴与 jev_* 工具）

推荐在 Web 端「设置 → 百工 Agent」顶部的「Jev 模型 API Key」卡片里粘贴 key 并「保存密钥」：它保存在 DSH 凭据存储中（引用名 `TYPESAFE_API_KEY`），不会写入任何配置文件，保存后立即生效；「测试连接」会列出账号可用的 Jev 模型。

也可以用环境变量提供（此时卡片显示「只读」）：

```powershell
setx TYPESAFE_API_KEY "<你的 Jev key>"
```

执行后关闭并重新打开终端，再启动 `dsh`。不配置也能用：衡鉴会只按规则分流，涉及算法改动的任务则走「严格路径」（强制验算与审查），专家交付后的衡鉴复评显示为「未执行」，`jev_*` 工具返回 401 与配置提示。插件内嵌了 Jev 工具与技能，不需要再单独安装 jev-mcp。

## 9. 检查

```powershell
npm run doctor -- --profile swarm
```

逐项处理带 ✗ 的项目。doctor 只检查凭据引用**是否存在**，不会读取或打印任何密钥值。

## 10. 使用

```powershell
cd <你的项目目录>
dsh --profile swarm web
```

打开 Web 界面，选择项目目录作为 Workspace，新建会话。默认预设就是「天枢」；也可以在预设列表中直接选「算衡」「妙笔」「复核」等角色。使用方法见 [使用.md](使用.md)。

## 卸载

```powershell
dsh plugin --profile swarm remove dsh-agent-swarm
```

卸载不会删除工作区文件，也不会删除账本（`%USERPROFILE%\.dsh\share\dsh-agent-swarm\ledger`）。
