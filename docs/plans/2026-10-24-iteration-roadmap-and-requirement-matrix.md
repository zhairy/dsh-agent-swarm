# 3.1.2–3.1.4 迭代总表与需求覆盖

日期：2026-10-24；2026-10-25按Ruflo源码研究修订。基线：已发布3.1.1；用户现已授权实施/验证/发布3.1.2，并升级唯一系统DSH到0.2.1-rc.3。下列3.1.3/3.1.4仍是后续计划，不能提前宣称实施或发布通过；3.1.2实际状态由本轮实施证据记录。

## 1. 本轮结论

采用原生“任务进度”主Tab，替代抽屉实施方向。当前已安装DSH0.2.1-rc.2公开`conversation.view`支持注册，顺序值20可排在对话0、轨迹10及Notebook15之后；不依赖Notebook、不修改宿主DOM。六图共用一个任务快照与读取层，按需绘制选中图，不能把移位置当成已修复刷新。

数学与授权强化没有完全遗漏：旧[迭代总纲](2026-10-23-self-evolution-3.1.1-through-3.1.4.md)原39–51行已列授权/凭证，53–81行已列相似度、全历史、DAG和审核边。本轮补足可执行契约、状态机、资源边界、反例和逐版本验收，并修正过强的数学表述。

文档使用顺序：本总表确定当前排期，版本计划确定交付契约，专项评估提供依据；2026-10-23抽屉/旧编号文件保留历史参考。运行实现事实以实际代码和测试为准，计划不得冒充已生效功能。

新增[Ruflo固定提交研究与采纳矩阵](2026-10-25-ruflo-design-adoption.md)。当前优先吸收独立任务工作区、单飞/新鲜度/导航状态分离、来源化不可执行候选；后续吸收可信事件投影、索引复用与独立对照回放。保持百工唯一执行控制面，不引入Ruflo运行时/第二MCP调度器、分布式共识或未经验证的学习阈值。

## 2. 分版本交付

| 版本 | P0与主目标 | 增量范围 | 不进入或不默认启用 |
| --- | --- | --- | --- |
| **3.1.2** | 原生任务进度Tab、六视角、共享读取/取消/过期提示、任务目录与隔离 | 受控技能/工具候选元数据、来源与隔离评测入口 | 不自动装载生成工具，不增加新工作流控制器，不引入语义硬阈值 |
| **3.1.3** | 权威验收receipt、真实授权等待、全历史结构新意、有限DAG激活与有界恢复 | 既有状态分片的有界控制记录；条件成立时评估版本推送 | 不以语义稳定判成功，不自动裁剪强制门禁，不声称无条件有限完成 |
| **3.1.4** | 四层治理、固定轨迹回放、校准、影子/显式Canary及回滚 | 可选咨询边观测收益、后续版本的受控提升 | 不训练权重，不对活跃任务热改权限，不以成本收益抵消安全违例 |

## 3. 需求覆盖与数学修正

| 用户需求/主张 | 当前3.1.1事实 | 本轮吸收及落点 |
| --- | --- | --- |
| 对话/轨迹/Notebook后放任务进度 | 仅有inline流程卡片 | 3.1.2公开主Tab，六导航、单一选中画布；无编排时说明未记录 |
| 进度不随聊天偏移或停止更新 | inline实例各有poller；超时/错误可能停止，旧Promise可继续挂起 | 3.1.2共享Store、真正取消、有限退避、身份generation与可见性管理 |
| 必须授权时询问而非自问自答 | 天枢5a指引与真实问答来源提取已有，硬等待未完整实现 | 3.1.3宿主ask_user_question、去重、未决状态、goal续轮抑制、晚答复/重启核对 |
| 未回复不能批准 | 指引已有；宿主权限仍独立约束 | 3.1.3 pending/超时/跳过/取消/无answerer不授予许可；真实答复也不覆盖never/deny |
| 门禁升级为独立硬守卫 | taskLock内证据门禁、DAG及最终派发检查已有 | 3.1.3同一权威迁移与服务器receipt；逐入口证明，类型本身不防伪 |
| 所有Jev结论均是验收前硬门禁 | 当前acceptance先保存，assessment随后追加；规划Jev另有准入政策 | 不混淆现状。若新政策要求验收Jev，3.1.3 prepare→独立评估→CAS commit |
| 语义震荡/低新意应停止空转 | 当前checkpoint基于问题原文和ref，非全局语义守卫 | 3.1.3精确结构进展为主，3.1.4校准语义观察；停滞不生成accepted |
| 相邻距离趋零就是固定点/熵归零 | 数学上不成立；余弦差也不是熵 | 明确反例、量纲/缺测/退化条件；不伪称Lyapunov或正确性证明 |
| 有限容量N保证N−1步 | 还需固定有限投影及全部历史新意/两两ε分离 | 3.1.3条件性命题，历史全局保留；到容量显式EXHAUSTED，不静默遗忘 |
| 窗口w能漏周期w+1 | 对仅局部重复查找成立，不适用于所有可保守停机的窗口算法 | 确定性反例与全局结构历史；未知Lean材料不充当依据 |
| DAG从结构上消除反复 | 当前已校验DAG，但无限激活/重规划仍可能继续 | 3.1.3固定图的代码调度与有限恢复谱系；长期等待不等于循环 |
| “修改—再评审”最多固定次数 | 次数是策略选择，不保证成功 | 3.1.3有限展开；最后通过仍正常验收，只有失败耗尽才升级 |
| 低收益审核边因果衰减/剪枝 | 未有可识别因果的实验基础 | 3.1.3记录、3.1.4校准可选咨询边；两周期不证明显著/无效，强制边永不自动剪 |
| 最大轮次降为最后防线 | 现有有限策略与预算仍需保留 | 结构重复/真实等待为主，语义先影子；不能在精确新意未落地前拆掉兜底 |
| 自动沉淀经验与工具 | 已有candidate及独立证据晋升，不是全无自动流程 | 3.1.2受控工具工件，3.1.4治理；“不自动提升”准确改为“不无审查提升” |
| 提升效率并避免过度工程 | Kahn核心线性，完整校验/历史派生另有开销 | 有界/增量/索引复用优先；不宣称整个系统O(1)，不先上嵌入服务/图数据库 |
| 吸收Ruflo设计优点 | 已固定源码commit并区分实现、ADR与宣称 | 3.1.2读取投影/来源候选；3.1.3成功提交后失效提示/索引；3.1.4回放/来源治理；不安装Ruflo运行时 |
| DSH升级rc.3并保留兼容 | 当前生产基线rc.2，既有engines范围保留 | 3.1.2隔离验证rc.3及rc.2/旧宿主，尊重rc.3导航定制；先保全状态再切唯一系统宿主 |

## 5. 共同工程约束

- 百工是唯一任务/证据/租约/执行事实源；原生Team仅只读投影，不接管完成。
- v1快照可读，旧入参兼容；新活动等待/凭证的旧读者必须拒绝不安全接管或只读降级。
- 所有推理模型输出及Jev判断只能在其被赋予的政策范围内使用，概率不是数学证明或用户许可。
- 保持Jev不新增本地限流/费用额度；不按价格放任无限同证据重复审核。
- 无依赖的已授权工作可继续；没有ready工作时安静等待，不按任意短截止杀死有实际进展的长任务。
- 所有实施先在隔离候选构建，不从生产链接目录构建造成提前HMR；正式切换保全真实状态、权限与单次交接。
- 3.1.1标签资产保留；3.1.2及DSHrc.3的实施、部署、验收、发布另有明确结果。切换前核对在途状态，不能静默重放业务或重建profile。

## 6. 本轮完成标准

2026-10-24文档阶段已完成独立MD方案与可审计评估；2026-10-25新增Ruflo一手研究后进入3.1.2实施。文档仍需全部条目有版本映射、Mermaid可解析、本地链接有效、旧入口指向新计划；代码阶段另须正反复审、明确payload的Jev、完整适当回归、真实宿主、打包/隔离安装、状态保全和匿名资产校验。
