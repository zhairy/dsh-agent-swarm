# 后续版本路线

本页区分已发布内容与仍在规划的方向；规划项不表示已经生效。

| 版本 | 状态 | 主要范围 |
| --- | --- | --- |
| 3.1.1 | 已发布 | 上下文引用恢复、已验证经验召回、规划审核模型显示、子会话安全选择、有界文件发现和错误恢复指引 |
| 3.1.2 | 已发布 | 隔离的技能/工具候选（只登记、不执行）；原生任务进度 Tab、六视角、共享 Store、真实取消、有界重试和过期提示 |
| 3.1.3 | 已发布 | 受管理入口的服务器验收凭证、全历史结构签名与有界恢复；真实用户问答等待；设置分类与备用链排序；路由和专家身份恢复 |
| 3.1.4–3.1.7 | 部分落地 | 只提供离线评测脚本 `scripts/evolution-evaluate.mjs` 与治理状态机库，尚未接入运行时、没有用户入口；独立 Diff Review、影子观察与按会话 opt-in 的 Canary 仍是规划 |

任务进度Tab将与聊天历史布局分离，取代旧抽屉方向，继续读取百工唯一事实源。组件必须按连接、根会话和任务ID隔离，校验版本、取消旧请求、丢弃迟到响应；六视角按需绘制，失败、阻塞、跳过单独计数，节点比例不等于工时、正确率或验收通过。

需要人工授权时通过 `tool-ask-user` 的 `ask_user_question` 提出具体选择。pending、超时或未回复都不授予权限；已授权的无依赖工作可继续，依赖授权的节点保持等待。

反空转以真实证据和状态机守卫为主。低语义变化只表示可能停滞，不表示任务成功；有限状态需要全历史新意条件，DAG 需要有限激活/重规划条件。强制验收、安全、风控和盲审依赖不会因“收益低”被自动删除。每阶段先独立验证，再发布。
