# 百工运行架构与性能优化实施记录

基线：2.3.1 / e38b0a6；2026-10-09。范围为源码审计和可复现验证；生产发布与内存任务热迁移另行实施。

1. 复现异步派发合同竞态和验收租约死锁；给可信执行信息增加固定合同与末端发布门禁；独立证据整理状态；将经验晋升和 Jev 验收复评移出任务锁；复评绑定具体验收记录。
2. 按 D-ID 管理恢复生命周期，finally 释放失败/取消历史；保留当前持久专家状态和 terminal 消费时序，拒绝迟到的取消模型请求。
3. 健康快照加入逐资源成功墓碑，兼容旧数组；真实成功受控提交，下次请求等待提交结果，失败明确转恢复；不绕过 provider reset，不以 LRU 遗忘水位。
4. 预算按启用限制计算、缓存小限额签名、单条预约 O(1) 查询；Jev 不施加速率和预算限制。不可变上下文缓存 UTF-8 字节数；采集/评分取消边界不发布新证据。
5. root/child 共享有界模型元数据成功及在途缓存，失败局部；每次检查真实 owner 资格；同一实际失败在同一健康注册表仅观察一次；规划独立路由并行预检。
6. 精确异常反馈，区分模型完成与证据整理、状态未提交、元数据等待取消和 SDK HTTP 取消；P2P 容量反馈不能虚构归档命令。
7. 30 样本/5 预热规模基准；全量类型/单测；私有候选构建和真实 DSH 沙箱；正反交叉审核及真实 Jev MCP。验证记录归档 docs/evidence/architecture-performance-2026-10-09。

验收不以“测试绿”替代架构边界：完整状态提交保留 O(S)，资源上限依然存在；不宣称端到端加速、token 降幅、原生 CLI 内部重试覆盖或未来永不出错。只有经证明的热点进入本轮优化。
