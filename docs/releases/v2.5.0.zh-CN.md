## ✨ 新增功能

- 任务卡新增工作流、委派架构、记录时序、合同与证据流、生命周期五种图表视角，共用同一版本快照，并支持导出 JSON、Mermaid 和 Archify 图表。
- 显示当前有效完成的委派节点进度，以及失败、阻塞、跳过、未知状态和流程偏移，便于核对实际执行与计划。
- 百工 Agent 设置新增简体中文、英文、繁体中文、日文、韩文交付语言；每次委派可单独指定，连续会话后续轮次也会应用语言约定。
- 新增有界 FIFO、优先级和轮询调度，支持按能力标签获取角色建议；排队仍遵守任务依赖、审批、预算和工作区执行边界。
- 可启用已复核经验的本地有界召回，为后续任务提供附带来源、适用条件和版本信息的参考，保留原始证据及独立审核隔离。

## 🐛 问题修复

- 修复编辑旧会话策略时，已保存的交付语言可能被重置的问题；消除旧提示中固定中文要求与新语言设置的冲突。
- 修复慢速任务状态请求可能被持续轮询丢弃、重复积累的问题；超时和读取失败时明确降级，保留可读源码与步骤。
- 修复关停时部分已启动委派尚未进入完整持久快照的竞态，并阻止延迟请求在关停后启动；已消耗预算保留，恢复后核对未知运行状态，不自动重放。
- 完善多会话关停清理与失败反馈，单个检查点失败仍继续清理其他存储，并保持重复关停幂等。

## 🎨 体验优化

- 同一源码不再重复渲染 Mermaid，减少只读刷新带来的图形重绘；五图派生复用单次快照，精确去重重复上下文路径。

## ⚠️ 其他变更

- 进度表示当前有效完成的委派节点比例，不代表工时、正确率或验收通过。图表诊断不会自行修改任务、批准流程或重放业务。
- 经验召回默认关闭，仅使用本根会话与工作区的已复核记录，适用性仍需重新验证；不会用历史回答跳过实际执行或本轮审核。
- 语言设置只约束可见交付，保留 JSON 键、代码、公式和证据路径原文；不因语言差异自动重试业务。
- Archify 为可选离线导出工具。五类格式已通过真实上游 standard 校验，数据流导出保留一条布局 warning，不宣称 showcase 视觉审核通过。
