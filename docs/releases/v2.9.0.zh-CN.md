## 🔍 与 0.2.1-rc.1 / rc.2 变更的逐项核对

| rc.1 / rc.2 变更 | 插件影响 | 处理 |
| --- | --- | --- |

| DeepSeek Search 与 Fetch API | 插件的外网取证走宿主 web 搜索/抓取 | 无需改动；沿用宿主能力，不另建客户端 |

| 输入区统计扩展拆成 activity / usage | 插件注册的是 `conversation.chat.node` 与 `conversation.session.header.actions` | 不受影响 |
| 移除工具展示 `both` 混合模式 | 全仓无 `both` 模式引用 | 不受影响 |
| 子路径插件不再读取独立 package.json | 插件为单入口（`./client` 由根 package.json 导出） | 不受影响 |
| 子智能体可配置独立 Agent Preset / 统一执行与完成通知 | 插件自 2.5.2 起已用 `agentPreset` 与双协议子智能体 | 集成测试覆盖 |
