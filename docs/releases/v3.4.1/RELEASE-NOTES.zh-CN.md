# DSH Agent Swarm v3.4.1

面向 DSH **0.2.2-rc.3**、Node.js **>=24.9.0** 的主工作区写入、Notebook 数据恢复与路由观测迭代。精确组件版本、文件摘要和本轮验证范围以随附 manifest、兼容矩阵与 verification-summary 为准。

## ✨ 新增功能

- Host 读取项目工作树规则及现有工作树数量，衡鉴结合当前需求作类型化模式判断：唯一主工作树用 primary，允许隔离时用 linked；矛盾或判断不确定时先澄清。判断本身不授予写权。
- 新增 `swarm_bind_primary_workspace`：路径和 owner 来自真实 Host，核验预期 HEAD、仓库/分支/目录、当前任务/attempt/版本和排他租约，可靠落盘后才激活。不创建第二工作树，也不改动原暂存、未暂存或未跟踪内容。
- 新增 `swarm_git_save`，用精确文件列表保存 WIP/提交；新增 `swarm_prepare_verification`，只为复核准备批准的临时目录和本次新报告写域，源码和 Git 元数据保持只读。
- Notebook 显式保存 .ipynb 后记录纯数据快照；通过 Host 持久任务关联恢复 cell、源码和输出的只读视图，保留历史来源，不恢复活内核、变量或执行权限。
- 既有任务视图新增脱敏路由时间线：请求/实际 attempt 关联、失败类型、预算、重试/等待及终态；不记录凭据、账号或原始错误正文。

## 🐛 问题修复

- 修复主仓库 `.git` 目录和根路径被一律按 linked 工作树拒绝的问题，同时保留独立工作树的身份、版本和冷恢复围栏。
- 阻止同一任务混合登记两类工作树、跨项目根/主分支恢复、使用与合同无关的 linked 基线，以及项目规则变化后继续沿用旧写权。
- 普通 Shell/文件工具不能改主仓库 Git 元数据；受控 Git 保存禁用 hooks、filter、签名和自动后台维护，部分失败保留现场，不自动重发。
- 复核允许写本次测试输出，不能据此修改源码或覆盖旧报告；目录替换和失效 attempt 均拒绝。
- 修复同号任务在不同根会话之间传播隔离状态或看门狗告警的问题；人工解除只作用于当前根会话，物理工作区租约围栏继续生效。
- 修复 Notebook 持久恢复的任务/项目混用及 Markdown/HTML/SVG 危险渲染；净化器随兼容组件分发，缺少净化能力时降级文本。
- 保留 Subscriptions 完整 overlay 和原有 rc.3 传输兼容修复；继续回归历史、等待、清理、预算和模型路由原有能力。

## 🎨 体验优化

- 界面显示工作区选择及规则依据，清楚区分需要澄清、Host 核验不可用和已有历史只读数据。
- 路由只读投影不因反复查询推进时间戳；省略计数明确为进程缓存总量，不能当成当前任务准确丢失数。
- 自动构建兼容总包、生成逐文件清单与校验和，验证声明入口、相对依赖、许可证及精确补丁往返；缺测和未知版本明确标为未验证。

## ⚠️ 其他变更

- Notebook 兼容包包含 DOMPurify 及其原许可证/来源信息；这些是本发布维护的社区兼容构建，不代表第三方上游发布。
- 新规划包含 Host 工作区事实；旧批准不能自动授予新模式写权。重启后恢复的是记录和数据，写入仍须当前授权与可信资源收尾。
- 兼容附件不包含 node_modules、Python venv、账号、Cookie、API Key、原会话或部署证据。
- 主树与 linked 沿用任务及租约串行规则，不承诺同一项目多作者无限并行、跨重启活变量恢复或无人值守无限纠错。

## 兼容性说明

- 本轮主要验收 Host 为 DSH **0.2.2-rc.3**。rc.1 桥接脚本保留；未执行的新版本/平台组合不得借历史测试标为通过。
- 受保护写入仍要求匹配的 Host 桥、Linux 本机、bwrap/native linux-scope 和 API Worker；PTC、持久终端和原生 CLI 私有写入没有新增豁免。
- Notebook 明确区分只读历史数据与当前执行；跨任务/工作树或目录身份不明时拒绝。继续计算需显式建立当前授权下的新 Notebook 或打开已保存文件，不自动重放旧 cell。
- 复核输出仅接受可有界核验的普通文件/目录；符号链接、多链接文件及未知节点拒绝，不自动清理原文件。Notebook 数据快照默认上限 16 MiB、4096 cells，超限明确报错。
- 普通 standard Notebook 保留原使用方式；它不等同于 Swarm 托管沙箱。外部 MCP 服务未启动、供应商限流或登录失效仍按实际状态处理。
- 安装前后核对磁盘、profile、服务 API 和浏览器；所有下载文件先验证 `SHA256SUMS`。升级/回滚保留匹配的程序、profile 和一致数据，不能覆盖已经产生的新历史。

### 附件与验证

主插件提供版本名与固定名同字节 tgz；兼容总包包含六个组件、完整补丁与许可证，Notebook/Subscriptions/RigorQuant另有单包。`third-party-manifest.json`、`release-manifest.json`、`verification-summary.json`、兼容矩阵和 `SHA256SUMS`分别描述来源、源码绑定、实际验证与校验和。

发布前执行完整回归、精确包 Host、真实数据保存/恢复、浏览器、本机安装和七项 Jev 辅助审核。Jev 判断不替代实际测试、权限校验或验收证据。
