## ✨ 新增功能

- 百工自动模型路由接入订阅额度来源，为天枢和各专家在实际调用时选择模型提供依据。直接读取 DSH 订阅插件返回的使用百分比、重置时间和套餐信息，保留数据来源，不使用本地调用次数或 Token 消耗推算套餐额度。
- 已确认账户归属且上报满额时，可优先尝试其他订阅模型；后移的订阅仍在 API 兜底前尝试，保留用户选型和首选恢复检查，避免因缓存长期停留在兜底模型。
- 新增纯函数计算设置，可按基础算术、整数/组合、统计、向量、矩阵、多项式、验证辅助 7 组管理 17 个算子，并选择 float64、bigint、rational 数值模式。支持设置单次输入、计算规模及任务累计调用与工作量上限，便于算法任务验证计算。
- 小矩阵和多项式计算可分别显式开启；禁用的算子在计算前拒绝，不消耗任务计算预算。

## 🐛 问题修复

- 修复均值、方差在大数及大偏置输入下可能因中间溢出而误报失败的问题，提高有限结果的稳定性；除零、越域和无法表示的结果仍明确失败。
- 额度依据区分账户、共享窗口和模型范围，避免重复统计或将不同单位相加；独立账户标识脱敏，配置冲突与数据缺失明确返回未知。
- 完善额度查询的取消、超限和异常反馈，避免把读取失败解释为额度耗尽；并发刷新共享读取，减少重复请求。
- 修复重复应用相同升级链时中断有效回退，以及专家创建成功后被重新选回启动失败模型的问题。
- 修复取消等待中的数学调用仍继续计算，以及超限输入被再次完整写入失败证据的问题。
- 完善从 2.3.2 升级时的任务交接，保留原任务、原始交付和已消耗预算。

## 🎨 体验优化

- 同一轮路由复用模型目录与额度快照，减少多账户、多模型池场景的重复扫描和临时分配；来源超时保持原模型链，避免额外长等待。

## ⚠️ 其他变更

- 订阅接口未公开供应商采样时刻；返回的读取时间不等于采样时间，强制刷新也可能返回订阅插件缓存。缓存或未知额度不直接判为耗尽，也不替代真实调用反馈、用户选定的模型及恢复检查。
- 当前 Qwen Token Plan、OpenCode Go、DeepSeek 官方 API 等接入未提供可复用的公开额度接口，返回未知；不将未知额度视为零或无限，也不宣称实时全覆盖。
- 各数值模式仍遵循算子自身的类型约束；计算结果用于核对给定输入，不代表算法或证明已通过验证。
