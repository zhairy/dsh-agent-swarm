# v3.1.6

🐛 问题修复

- 一次性专家结束后释放工具作用域、提示、信号、就绪状态和所有者映射；普通已完成控制记录与仍需副作用复核的记录分别受 256 条硬上限保护，隐藏或延迟的工具调用继续被拒绝。
- 任务验收或明确未完成后只回收所属根会话中已停稳的子会话控制记录；即使删除最后一条记录也会持久化该根会话的空快照，避免同名 `T-1` 跨会话误删或重启后复活；`swarm_status` 使用不生成六图的紧凑投影。
- 修复任务进度读取在最后一个订阅离开、底层传输随后才结算时占用缓存容量的情况；连接反复重建且取消不合作时，旧代际在途请求也进入有界集合并计入真实 in-flight 诊断。
- 修复专家“模型与恢复”面板在命令未结算时关闭后永久停在“处理中”、页面隐藏时仍周期性读取宿主状态的问题。
- 修复连接重建与设置保存的竞态；旧连接下的迟到保存结果不会清空新草稿、覆盖 Jev 密钥输入或让保存状态卡住。
- 模型目录读取增加 15 秒超时与可重试错误态；会话策略中已隐藏的比例字段不再把半成品输入写成无效数值。
- 统一 Mermaid 解析器版本来源，规划审核记录不再硬编码旧版本号。
- Mermaid 初始化抛错会拒绝本次加载并允许后续重试，不再留下永久悬挂的模块级 Promise。
- 修复 ESM 宿主中 Mermaid Worker 的 CommonJS 入口，真实官方解析器可在隔离 DOM Worker 中正常运行。

🔒 安全与依赖

- Mermaid 升级至 12.2.0。Node 侧解析器解析到 DOMPurify 3.4.17 与 KaTeX 0.18.10；浏览器预打包资源仍内嵌 DOMPurify 3.4.12，因此渲染继续使用 `strict`、关闭 HTML 标签并复核 SVG 白名单。
- 生产依赖审计无已知漏洞；现有 Mermaid 语法、投影、SVG 安全与客户端回归继续通过。

⚡ 性能与工程质量

- 增量状态按段缓存精确 UTF-8 字节数，未变分片不再在每次容量检查中重复遍历；若干分片删除与顺序检查由线性查找改为集合查询。
- 发布白名单改为显式用户文档，打包守卫拒绝 PRD、实施计划、内部证据、源码和测试。
- 发布目录同时生成版本化 tarball 与稳定下载别名 `dsh-agent-swarm.tgz`，两者写入同一组校验和；安装文档的版本化路径、源码链接和源码仓库专用命令已修正。
- 发布包排除只供开发期预设生成使用的构建模块，避免非运行时文件进入用户安装。
- 补齐生成类型声明实际引用的 Cosmokit 直接依赖，避免严格包管理器或 TypeScript 消费方解析失败。
- 启用 TypeScript 未使用局部变量与参数检查，清理确认无用的导入。

🧪 验证

- 111 个单元测试文件通过，1511 项通过、4 项跳过；语句覆盖率 88.93%，行覆盖率 94.71%。
- DSH 0.2.1-rc.3 集成测试 49 项通过；类型检查、构建、覆盖率、发布闭包与精确 tarball 隔离安装均纳入发布门禁。
- 真实 3080 Web 宿主、关键页面交互和浏览器控制台在本机验证后发布。

兼容范围为 `dsh >=0.2.0-rc.2 <0.3.0`、`Node.js >=22.12.0`；已提交任务、证据、门禁、租约和状态 schema 不做破坏性迁移。
