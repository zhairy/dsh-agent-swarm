# v3.1.6

🐛 Fixes

- Releases one-shot expert tool scopes, prompts, signals, readiness and owner mappings when a run ends. Ordinary settled controls and still-unreviewed side effects are each hard-bounded at 256 records, and hidden or late tool calls remain denied.
- Terminal tasks release settled expert controls only within the owning root session. Deleting the final control record now persists an empty snapshot for that root, preventing cross-root `T-1` deletion and restart resurrection. `swarm_status` uses a compact projection without diagram generation.
- Fixes task-view reads retaining capacity after the final subscriber leaves. Uncancellable requests from replaced connections now enter a bounded detached set and appear in real in-flight diagnostics.
- Fixes the expert model/recovery panel remaining permanently busy when closed before a command settles, while preserving hidden-page polling suppression.
- Fixes a connection-reset/save race so a late result from the old connection cannot clear new drafts, overwrite a new Jev key input or leave saving stuck.
- Adds a retryable 15-second timeout for model-catalog reads and prevents hidden session-policy controls from saving half-edited invalid ratios.
- Uses the installed Mermaid dependency as the single parser-version source instead of recording a stale hard-coded version.
- Makes Mermaid initialization failures reject the current load and recover for a later retry instead of leaving a module-level Promise hanging forever.
- Fixes the Mermaid Worker's CommonJS entry under an ESM host so the official parser runs inside the isolated DOM worker.

🔒 Security And Dependencies

- Updates Mermaid to 12.2.0. The Node-side parser resolves DOMPurify 3.4.17 and KaTeX 0.18.10; Mermaid's browser prebundle still embeds DOMPurify 3.4.12, so rendering keeps `strict`, disabled HTML labels and SVG allowlist checks.
- The production dependency audit reports no known vulnerabilities. Existing Mermaid syntax, projection, SVG-safety and client regressions continue to pass.

⚡ Performance And Quality

- Caches exact UTF-8 segment sizes for incremental state capacity checks, avoiding repeated scans of unchanged chunks; several chunk-removal and order checks now use sets.
- Uses an explicit user-document whitelist and rejects PRDs, plans, internal evidence, source and tests from the release tarball.
- Publishes both the versioned tarball and the stable `dsh-agent-swarm.tgz` alias with the same SHA-256, and fixes versioned install paths plus source-repository-only links and commands.
- Excludes the build module used only by development-time preset generation from the published runtime files.
- Declares Cosmokit directly because generated types reference it, avoiding resolution failures in strict package managers and TypeScript consumers.
- Enables TypeScript checks for unused locals and parameters and removes confirmed stale imports.

🧪 Verification

- All 111 unit-test files pass with 1511 tests passed and 4 skipped; statement coverage is 88.93% and line coverage is 94.71%.
- All 49 DSH 0.2.1-rc.3 integration tests pass; type checking, build, coverage, release closure and exact-tarball isolated installation are release gates.
- The real Web host on port 3080, key interactions and the browser console are verified locally before publication.

Compatibility is `dsh >=0.2.0-rc.2 <0.3.0` and `Node.js >=22.12.0`. Existing task, evidence, gate, lease and state schemas receive no destructive migration.
