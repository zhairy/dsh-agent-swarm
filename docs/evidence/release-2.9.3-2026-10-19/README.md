# 2.9.3 发布验证

2026-10-19。2.9.3 是 2.9.2 之后的规划审核恢复补丁，代码基线来自本机人工验收过的 `8dc217a`，本次发布只增加版本号、README 入口和发布说明。

## 本次包含的修复

- 规划审核默认不设总时长上限，持续工作的审核模型不再被 180 秒截止取消；用户取消、宿主停止和版本变化后的结果仍被拒绝。
- 异步问答的确认与选项可跨历史压缩保留；取消、调用身份不匹配或结构无效的问答不作为授权。
- 超过有效页大小的上下文请求自动收窄并返回实际大小与下一游标。
- 已返回但结构校验不合格的审核直接展示最多 12 条具体发现，不误报为服务故障。
- 任务卡和状态显示真实 `workflowMode`，恢复提示区分建议模式与强制模式。
