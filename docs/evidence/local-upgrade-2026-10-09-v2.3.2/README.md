## 升级与真实生产验证

- 停服前确认没有运行任务，可信 owner 在任务锁内完成全量 checkpoint，备份完整已校验状态、编译产物和配置；仅一个非空内存 owner，未遗漏其他任务所有者。
- 离线严格验证本次快照后，以真实来源 2.3.1 暂存交接；没有调用历史事故专用的版本恢复或预算撤销逻辑。
- 停止唯一服务后更新版本并构建，再启动同一服务。激活原根会话只消费交接一次，随后全量写入序列 0→1，严格校验成功。
- T-1 的合同/流程/原始请求版本仍为 **2/4/1**；两份原始交付保持字节摘要不变，历史流程修订保持 2，已发送预算没有退还。原任务规划审核仍为 **unavailable**，升级测试不构成该任务的审核通过。
- 配置与 profile 文件无差异；第三方 expert-mode 的 46 个预设文件内容与权限不变；业务源码与状态摘要不变。维护临时条目全部移除，未开放 inspector 网络监听器。
