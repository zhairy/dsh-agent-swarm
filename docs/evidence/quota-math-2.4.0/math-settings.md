# 2.4.0 纯函数算子设置与数值审查

本轮新增「设置 → 百工 Agent → 纯函数数学算子」卡片，包含全局开关、7 个算子组、17 个单独算子、3 种数值模式、每任务调用数/累计工作量及 11 项单次规模限制。算子组与高级限制折叠显示；配置走现有 `configForms.mutate(ops, revision)`，可与路由、会话和审批设置原子保存，继续保留宿主 CAS 冲突检查和只读部署限制。

## 授权与兼容

- 实际授权为 `全局开启 AND 组开启 AND 算子开启 AND 模式开启`，服务在预留预算前检查，纯函数内核再次检查，拒绝结果为结构化错误且 `workUnits=0`。
- `matrix`、`polynomial` 默认关闭。旧 `enableExtended=true` 在没有对应显式组值时兼容开启这两组；显式 `false` 优先。设置页保存后使用显式组值并清除旧扩展开关，不会下次加载又将关闭组重新开启。
- `residual_norm({residual})` 可以独立使用；组合 `A,x,b` 同时需要验证组、`residual_norm`、矩阵组与 `matmul`，不能借残差算子绕过矩阵授权。
- 算术接受 `float64`、`bigint`、`rational`；精确 `compare` 仅接受整数/有理数，`compare_close` 仅接受有限 float64 和显式非负容差。整数为十进制字符串，不进行跨类型隐式转换。`binomial` 的 `n,k` 保持已有安全整数参数形状。
- 未知权限键、非法配置容器与不合法限制整体拒绝数学计算；顶层未来无关配置在保存时保留。显式「恢复默认」可清除非法授权键与派生错误标记，不会清除顶层无关字段。输入访问器在授权预检中也不会执行。
- 调用数的旧 `0=不限` 语义保留，最大可配置值为 1,000,000；累计数学工作量必须为正安全整数，默认 1,000,000，上限 10,000,000。该上限不是可执行百万次的承诺，完整状态容量、上下文容量和单次限制仍然适用。
- 11 项单次限制的默认值保持不变，UI 与后端从 `math/config.ts` 同源取得默认、算子表和最大值；硬上限为对应默认值的 4 倍。每次工作量取配置单次上限和任务剩余额度的较小值。数学单位用于本地计算，与模型订阅、token 或 Jev 不限额策略无关。

## 正反论证与已修复反例

反方专家提出组/算子/模式联合授权、未知授权键、非法容器、资源硬上限、剩余额度钳位、矩阵组合残差旁路和重置不可恢复风险。实现采纳并增加了对应回归。

反方数值审查发现：旧均值先求和，`mean([1e308,1e308])` 的有限正确结果 `1e308` 会被中间求和溢出拒绝；旧 Welford 方差的 `M2` 累积会在 `variance([1e154,-1e154], ddof=0)` 的有限结果约 `1e308` 前溢出。

- `mean` 优先 Neumaier 补偿求和后除以 n，保留大数消去中的小项；只有 `NON_FINITE` 中间溢出时使用 max-abs 缩放求均值。其他错误和工作量限制不被吞掉，回退计算追加实际工作单位。另验证 `[1e308,1e-15,-1e308]`，避免一律缩放抹掉小项。
- `variance` 使用移位、缩放、补偿的两遍算法：有限时先减去首项以保持大偏置下的小差值；相反极值差溢出时改为整值缩放。先求标准差再平方，避免有限方差被未归一化平方和的溢出误拒绝。
- 回归包括 `[1e12,1e12+1,1e12+2]` 的 `2/3`、可表示次正规结果 `[1e-160,-1e-160]` 的约 `1e-320`、`ddof=1` 真溢出仍拒绝以及缩放 norm2 大值。
- `matmul` 在输出计算前一次扣除全部 `2*m*k*n` 内核工作单位；组合残差一次扣除 `2*m*k+2*m`，包括点积、减法与范数。输入校验/读取计费另算，不再在输出循环中重复扣除内核工作量。
- 数值内核证据 `operatorVersion` 升为 `2`，重现摘要绑定新版本；请求协议 `version=1` 继续兼容，旧证据保留原版本而不重写。

## 时间与空间复杂度

表中空间包括计算所需副本/输出；所有调用还有与有限输入 JSON 字节数成正比的校验和摘要开销。

| 算子 | 时间 | 额外空间与边界 |
| --- | --- | --- |
| float64 基础算术、compare_close | O(1) | O(1)；比较使用有限 binary64 的精确 dyadic 表示，固定精度有界 |
| bigint/rational 算术、gcd/lcm | 依整数位宽与底层 BigInt 算术；Euclid 为 O(log min(a,b)) 次余数步骤 | O(B) 级整数表示，输入/中间/输出位数分别限制；不将算术操作次数冒充真实 CPU 时间 |
| binomial | O(min(k,n-k)) 次有界 BigInt 乘除 | O(B)；n 和整数位数/work 均有界 |
| sum、mean、variance | O(n) | O(n) 包括输入副本；mean 常规补偿求和、溢出时常数遍回退；方差增加常数个 O(n) 数组换取极值与偏置稳定性 |
| dot、norm2、显式残差 | O(n) | O(n) 包括输入/乘积副本；norm 内核本身只需要 O(1) 累积状态 |
| matmul | O(mkn) | O(mk+kn+mn+k)，矩形/维度/输出/乘加数与工作量预检 |
| poly_eval | O(n) Horner | O(n) 包括系数副本；内核累计值 O(1) |
| A,x,b 残差 | O(mk) | O(mk+k+m)，矩阵授权和规模边界同时适用 |

没有引入依赖、eval、代码表达式执行、时钟、随机数、环境读取或外部 I/O。float64 仍为近似计算，不承诺跨引擎逐位相同；计算证据不能替代数学证明。此轮不以算子微优化声称整个模型任务提速。
