# 多图、进度和 Archify 导出审核

五图从同一 `TaskRecord.workflowDefinition/workflowState` 与版本化委派记录同步派生，使用相同的合同／流程／需求修订和 `snapshotDigest`。没有新增可写执行状态，没有 `currentProgress++`，没有由图重绘触发的补偿委派、门禁放行或审核版本变更。旧 `flow.mermaid` 与 Markdown 保留兼容。

| 视角 | 来源与边界 |
| --- | --- |
| 工作流 | 原始版本化 DAG，颜色为当前节点状态；完成节点须匹配同版本、同角色、当前 attempt 的唯一有效完成交付。 |
| 委派架构 | 本任务实际已登记委派的角色关系；不编造外部 API、数据库或部署拓扑。 |
| 委派记录时序 | `startedAt` 在 queued 建记录时写入，表示登记并包含等待；终结取已记录 `finishedAt`，或有限非负 `durationMs`；缺结束不绘返回。旧版本明确标注。不是逐模型调用日志，也不把纵向位置当耗时比例。 |
| 合同与证据流 | 合同、已登记上下文、委派与证据的数量和所有权关联；不复制提示词、文件正文或凭据。 |
| 生命周期快照 | 当前节点状态分布，包含控制节点。没有状态迁移历史日志时不编造迁移。 |

进度是「当前有效完成的委派节点数 / 当前 DAG 中委派节点总数」。失败、阻塞、跳过和未知单列，控制节点不进入分母；零委派节点显示不适用。百分比不表示工时、正确率、审核通过或业务验收通过。旧 attempt、陈旧修订、未最终提交的输出、重复完成绑定和过期验证产物不计入完成。

偏移诊断覆盖流程摘要不符、缺失／多余状态节点、完成绑定不成立、已开始节点仍有未完成依赖。诊断只提供人工核对线索，不能自动修复或重放副作用。RPC 的待同步只读投影在界面明确标注。

客户端显示一张主图，以原生下拉切换视角，保留键盘可操作的缩放、横向滚动、步骤和源码。所有来源先经有界语法白名单，再由本地 Mermaid 11.12.0 strict 模式渲染，最后拒绝含脚本、外部链接和危险标签的 SVG。图包版本不一致或结构异常时回退到原始流程，不把异常视图当成功。图更新不修改规划审核。

反方复现了固定 5 秒 interval 的联动缺陷：慢于 5 秒的 RPC 会持续被下一轮失效并叠加。修复为组件级单请求和成功返回后 5 秒再轮询；失败或 15 秒等待超时停止自动读取，需手动刷新。旧请求未结束时新刷新等待它，过期等待者不得继续投递；迟到响应和卸载后的结果不得发布。等待超时不宣称底层 RPC 已取消。页面隐藏时暂停请求，同一 Mermaid 源码不重复渲染。

Archify 是显式离线导出的可选外部 CLI，不是生产运行依赖。已浅克隆其真实上游并锁定：

- 仓库：<https://github.com/tt-a1i/archify>
- 提交：`58ab0b98d2d0def8e49dced705c7b566936723ec`
- CLI 版本：`3.0.1`
- 模式：architecture／sequence／dataflow schema 1，workflow／lifecycle schema 2。

上游五种 JSON schema 已核对并实施真实适配。初轮实测发现 workflow v1 固定列重叠且中文标签超宽，修为 v2、DAG 深度分列与按标签宽度分配节点；lifecycle v1 会绘隐式阶段轨道，修为 v2 且仅使用显式迁移，避免把快照伪造成历史。

`scripts/export-task-diagrams.mjs` 接收浏览器导出的快照或 taskView RPC JSON，导出五种 Mermaid 源码和可用 Archify IR；指定 `--archify` 后运行真实 `validate` / `deliver` 并保存收据。输入上限 1 MiB，单图源码上限 32 KiB，委派历史保留最近 32 条并明确截断数；新目录输出避免误覆盖已有文件。无时间事件时，Archify sequence schema 要求至少一条 message，导出明确标记 unavailable，不伪造消息凑齐 schema。

合成任务 fixture 的最终五类 `validate` / `deliver` 均退出 0；上游 standard 基础检查每类通过 9 项，收据包含 IR 与 HTML SHA-256。dataflow 保留 1 条微线段 warning。这里没有运行上游 visual-check 或宣称 showcase 视觉质量，也不能将导出检查当作流程授权／业务验收。可核对 [真实收据摘要](archify-verification.json)。

复杂度：当前实现对 D 条委派过滤和投影后排序，时间 `O(D log D + V + E)`，额外临时内存 `O(D + V + E)`，最终图与历史输出 `O(V + E + min(D, 32))`。V、E 沿用当前流程 32 节点／64 边硬上限。Archify 几何布局是仅在显式导出执行的有界图遍历；不在每次 Agent 调用链中执行，不产生额外模型调用或 Token 费用。
