## 3. 修复后的关键规则

```text
有效批准 = 当前快照 ∧ 当前题目版本 ∧ 当前身份和策略 ∧ 审核通过
同一明确负结论 + 无实质合同变化 = 返回原结论（不新调用模型）
阶段验收通过 ≠ 整体长期目标完成
```

设需求集合 R、本阶段交付 S、延期 D、全局安全约束 C。合格阶段需要 S∪D=R、S∩D=∅，且 C 在本阶段成立。这是审核义务；自然语言分类依赖实质审核，不能把字段存在当作证明。

若独立抽样的单次误通过概率为 p，重复 n 次至少一次误通过概率为 1−(1−p)^n。此式说明反复抽签的风险；不是 Jev 实测误判率，也不假设真实模型响应必然独立。

复杂度：需求读取仍需扫描宿主可见历史 O(H)；快照编码与哈希仍与当前任务文本大小有关。此次优化减少重复文本和远端模型请求，没有宣称整体 O(1)。缓存命中将同快照后续语义模型调用数降为零；存储保留最近结论，无新增无限审核历史列表。
