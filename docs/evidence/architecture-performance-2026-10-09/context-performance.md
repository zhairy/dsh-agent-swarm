# 上下文分页与取消：反方审核、实现及测量

审核对象为 2.3.1 基线源码及本轮限定改动。未修改生产配置、私有任务状态或运行中的宿主，也没有发出真实模型请求。

## 可证实的成本

`ContextStore.Read` 只返回一页字符，却每次执行 `Buffer.byteLength(artifact.text, 'utf8')` 重新扫描全文；`List` 同样重新扫描每个材料正文。UTF-16 字符游标和 UTF-8 字节数是不同单位，不能直接用 `text.length` 替代字节数。

设正文 UTF-8 字节数为 A、UTF-16 长度为 C、页宽为 p。旧路径读完全部分页的计数成本为 O(A × ceil(C/p))；索引成本含 O(ΣA)。改动在验证私有不可变材料时计算字节数，以对象身份保存在 WeakMap。每次读取仍经过原有根会话、工作区、任务、三个修订、线程、盲审和摘要检查。缓存不包含权限判断，不进入持久格式，不复制正文，也不会单独保留已删除材料。

改动后分页成本上界为 O(C + 页数 × 授权检查)，索引不再扫描正文，新增空间为每个私有材料一个弱引用整数项。Add、Restore、准备/提交/回滚均复用同一验证入口，避免出现未建立计数的公开写入路径。

## 可重复基准

命令：

```bash
node scripts/bench-context.mjs --baseline-dir <2.3.1编译目录> --current-dir <本轮编译目录> --samples 30 --warmup 5 --output <结果.json>
```

原始样本、Node/CPU、编译模块 SHA-256 见 [context-benchmark.json](./context-benchmark.json)。基线为当时未重建的 2.3.1 `lib`；改后源码仅编译到 `/tmp`，未覆盖生产引用的 `lib`。两个版本在同一进程交替顺序运行，每组预热 5 次并保留 30 个样本。

| 情形 | 操作 | 基线 median / p95，ms | 改后 median / p95，ms |
| --- | --- | --- | --- |
| 1,024 字节 ASCII，1 页 | 读完分页 | 0.00486 / 0.02935 | 0.00453 / 0.02560 |
| 983,040 字节中英文/emoji，66 页 | 读完分页 | 61.25610 / 67.64069 | 0.04351 / 0.12122 |
| 同一大材料 | 索引一次 | 0.97471 / 1.19989 | 0.00450 / 0.01862 |

两个独立 Node 进程强制 GC，测量 256 个存活小材料的增量 retained heap：基线中位 141,296 字节，改后 148,968 字节，差值 7,672 字节，约 30 字节/材料。原始区间存在 GC 波动，该值是成本估计，不是内存上界或生产峰值。

大 Unicode 材料的改善来自移除反复全文计数；不代表整个任务、NAS I/O、模型调用或 token 使用获得同样比例的改善。小材料处于微秒量级和调度噪声范围，不能据此宣称稳定加速。

## 取消路径

旧代码在信号已经取消时仍完成本地文件采集，并为每条主张调用评分入口。合成 100 条主张产生 100 次假 ask 调用；真实客户端会阻止 HTTP，因此此复现不等于“取消后发出 100 个真实网络请求”。

本轮在入口、真实路径校验、私有路径检查、文件打开后、读循环、读取/来源抓取完成后和评分边界检查取消。文件句柄仍通过 `finally` 关闭；已经发出的调用保留实际用量观察。取消返回无新评估，不把缺失评分装成一份正常 unknown 评估，也不改变原始交付。后续服务层必须同时阻止取消后的新成功上下文发布。

回归覆盖：预取消不启动采集/评分入口；20 个不同来源在首个抓取触发取消后不再启动其余抓取；100 条主张在首个判断触发取消后不再启动后续判断，原交付保持原样。三个回归先在基线失败，再在改动后通过。上下文新增 Unicode 多页重组、返回副本隔离、缓存预热后权限拒绝、恢复格式不变及事务回滚检查。

本模块定向运行：上下文 13 项、证据评估 20 项、证据服务集成 12 项，共 45 项通过。全项目验证由总审核另行汇总。
