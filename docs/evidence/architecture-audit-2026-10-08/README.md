# 2.2.1 架构、审批与性能验收

本轮沿用 2.2.0 的分层结构，修复实际错误分类、数值阈值、状态归属和恢复清理问题，并加入可配置的工具审批。开发回合 MCP、DSH 工具执行、插件内部 HTTP 与原生客户端权限属于不同层；本轮没有修改外层策略或把历史拒绝记为通过。

当前七项 Jev MCP 工具已实际返回成功；[输入快照](jev-audit-state.json)和[全部结果](jev-audit-results.json)保留初次输入格式错误、证据不足项及其更正，模型概率只作辅助判断。工程依据见[审批审查](engineering-review.md)，状态复杂度与复现实验见[性能审查](performance-review.md)。

## 修改与复用

- 工具审批通过公共 pre-execute 组合额外请求/拒绝，默认继承宿主；最终守卫保留角色、版本、取消、范围和租约约束。未自答许可、覆盖 never 或宣称控制 native 私有工具。
- Jev 的响应与失败分类、概率/评分合法性复用同一组函数。坏响应不当网络错误重试，取消即时退出，权限拒绝不转用其他凭据，非可用性失败不被可选规划审核降级为通过。比较保留原精度，显示再舍入。
- 任务绑定与版本比较使用公共纯函数；幂等请求使用 canonical 对象摘要，保留旧顺序摘要的兼容检查。预约锁等待期间改版会拒绝执行。任务/委派身份不能迁移，关联先准备再同步提交，避免重复索引或孤儿记录。
- 状态保留完整校验、串行提交、落盘成功后发布及 v1 校验格式。复用 canonical 字节、按需克隆子树；初始化、恢复及 owner 清理有负控。
- 删除无用导入与重复校验；不破坏公开兼容 API。旧请求限流器标为 deprecated，生产 Jev 客户端不调用；未接线的公开规划存储仍保留兼容。`tsc --noUnusedLocals --noUnusedParameters` 通过。

## 复杂度与取舍

以 B 表示完整状态字节数、P 表示选取子树字节数、T/D 表示任务/委派数量：

| 路径 | 时间与空间 |
| --- | --- |
| 完整 read/commit | 仍需 O(B) 克隆或校验；canonical 编码中各对象键排序。缓存增加 O(B) 常驻空间，减少重复编码；磁盘提交仍含 fsync，不承诺 O(1)。 |
| readPath/readFields | 克隆成本随选中子树 P 增长；同次多字段来自一个状态版本，不向调用者暴露可变内部引用。 |
| 任务归属验证 | 从 O(TD + ΣD_t²) 重复扫描改为哈希索引的均摊 O(T+D)，新增 O(T+D) 临时索引。 |
| 添加委派 | 为保留原任务引用的不可变更新，关联数组复制仍为 O(D_t)；没有以性能名义跳过身份或索引校验。 |
| 题目选项打乱 | 缓存原始键集合，避免循环里反复 Object.keys，从 O(n²) 重复构造降为 O(n)。 |

不为减少行数改写整个协调器，也不使用文件 mtime 缓存来代替真实产物摘要。DAG 有32节点/64边边界，优先优化实测的大状态复制和任务关联扫描。完整状态日志、协调器多对象更新不被宣称为跨文件分布式事务；任意 shell/native、NFS 掉电与完整在线质量仍不在本次验证范围。

## 验收

完整单元测试498/498、真实宿主配合模拟服务的集成20/20通过；行覆盖96.13%、分支83.06%，类型、无未使用符号检查和构建通过。审批组件桌面/移动 QA 见 [记录](functional-jev-approval-qa.json)。本地合成内存基准不等于磁盘、NAS、模型耗时或 token 节省。

本轮发布说明只列功能变化与影响，审计记录保留在本目录。2.2.0 历史开发阶段未获最终 Jev 复审的事实保持原记录；本轮新的真实审核不回写或伪造那次历史执行。
