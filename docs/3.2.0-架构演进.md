# 3.2.0 重大重构

3.2.0 属于重大内部重构。它保留百工已经验证的领域能力和用户行为，替换长期累积的单体编排、分散路由状态、多套恢复分支和巨型前端模块。

“设置 → 百工 Agent → 模型路由”在 3.2.0 中默认收起全部专家卡。卡片头部始终显示专家名称、角色标题、状态和主模型摘要；点击向下按钮展开主备模型链与升级链，再次点击向上按钮收起。每张卡独立控制，折叠不会改变配置或草稿。

Jev 设置增加官方/第三方互斥开关。官方模式继续使用 TypeSafe API key；第三方模式从 DSH 实时模型目录提供供应商、模型、推理强度三个下拉框，并沿用该供应商的认证、额度、模型资格和宿主权限。官方密钥在第三方模式下不读取，第三方模型响应必须满足 Jev 的 typed answer schema，无法解析、超时或供应商失败时按受控失败返回。

可编辑工作区的专家使用 DSH 官方 `create_worktree`。工作树从本地 `HEAD` 建分支并在新目录中继续执行；Ticket/Assignment/Agent 与路径、分支、基准提交绑定，禁止跨任务复用或创建第二棵可写树。工作树默认人工保留，不提供自动删除；重启后由账本恢复为 `recovery-required`，避免自动清理未提交改动或未合并提交。

## 保留的能力

- 14 个专家角色、角色职责与预设。
- DSH sandbox、approval、工具准入和 Agent 身份。
- 供应商额度、认证、模型目录、推理档位与模型资格。
- 每角色主模型、备用链、升级链、熔断、半开探测和恢复。
- 任务卡、规划审核、Jev、御史/复核、证据门禁和验收。
- 连续专家会话、模型调用显示和专家语言排除。
- TypeSafe 官方 Jev 与 DSH 目录中的第三方 Jev 兼容模型。
- DSH 原生 Git worktree 隔离、任务绑定和人工保留。

## 重建的内部

- Router 只负责规划、授权、路由和派发；Worker 只执行固定 Ticket。
- 路由目录、资源、失败分类、健康、升级和恢复收敛为单一 RouteEngine。
- 事件先过滤、去重并校验 revision/lease，再进入 EventJournal V2。
- Ticket、Route、Health 和 Progress 由事件生成只读投影，UI 不重新计算业务结论。
- Watchdog 只告警、暂停和隔离未知副作用，不自动重放写操作。
- 主动工作提供 `off / observe / auto` 三档，默认 `observe`。
- 3.1.9 状态通过一次性 Importer 转换；切换后删除旧状态机和兼容分支。
