# 3.1.1 上下文经验与宿主恢复

## 1. 背景

3.1.0 已修复事件窗口渲染中断。后续真实任务暴露规划审核模型不可见、子会话缺少模型切换入口、上下文旧引用失败、宿主 glob 原始输出超过 20 MB 和 DeepSeek Fetch 404。工具失败不能冒充任务验收失败，也不能通过放大缓冲或变更可信端点掩盖。

## 2. 目标

- 根据真实请求与路由观察显示规划审核模型，未知信息明确标记。
- 子会话在宿主支持的控制入口安全选择后续请求模型，保持任务、权限、租约和独立审查约束。
- 上下文索引/引用失效给出版本绑定的恢复方式；经验只从已审查条目读取，盲审不读作者历史。
- 在当前工作区子目录有界枚举实际文件，避免无边界 glob；保留取消、私有路径和符号链接隔离。
- 宿主已知工具失败保留原始错误码、isError 和证据语义，补上可操作反馈，不自动重复失败请求。
- 把四层自我进化调整为 3.1.1–3.1.4，区分可证明的状态机守卫与需要实测校准的语义启发式。
- 追加：天枢使用 tool-ask-user 提出确需用户授权的选择，等待不等于批准；问题去重、恢复和答复版本绑定状态机列入 3.1.3。

## 3. 修改范围

- `client/model-events.js`、`client/model-display.js` 及相关控制/路由模块：观察真实模型与安全切换。
- `src/context-store.ts`、`src/service.ts` 等：引用失效诊断及已有经验链路的最小增强。
- `src/project-discovery.ts`、`src/task-tools.ts`：子目录、有界响应、取消和检索提示。
- `src/tool-recovery.ts`、`src/index.ts`：仅百工管理会话的工具失败恢复说明。
- `docs/plans/2026-10-23-self-evolution-four-layers.md`：版本路线、数学假设、验证与回滚。
- `tests/unit/`、`tests/integration/`：必要的跨任务/旧版本/宿主契约回归。

## 4. 数据结构与 API

`swarm_project_files` 可选新增 `path`（工作区相对目录），已有参数保持兼容。只读响应增加明确截断/遍历范围信息。失效上下文不得自动转到其他任务。模型切换复用现有会话控制 API，不引入第二调度器。核心状态 schema 不作不必要迁移。

## 5. 风险与边界

不调整宿主 glob 的内存安全上限；不替用户修改 Search/Fetch API 地址或发送凭据到新地址。语义收敛只能触发停滞诊断，不能签发验收。安全审核边不可因低收益被删除。常数时间哈希查重只适用于固定长度结构化签名，不能声称任意语义等价判断为 O(1)。

## 6. 验证方式

类型检查、全量单元测试、真实 DSH AgentLoop 集成、构建、tarball 模块依赖闭包/隔离安装；正反两路 Agent 与 Jev 七种工具的明确 payload 复审；本机单实例 3080 宿主浏览器、模型展示/切换与上下文读取验证。未验证项如实记录，不以健康检查代替真实请求。

## 7. 回滚方案

保留已发布 3.1.0 与部署前 profile 备份。候选在独立目录构建，正式宿主空闲后受控切换内容摘要 link 安装；异常恢复原 package/lockfile/插件目录引用并重启唯一 dsh-web 服务。3.1.1 未满足验证前不发布；不覆盖 3.1.0 标签或资产。
