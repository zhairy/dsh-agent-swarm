# v3.4.0 公开兼容附件修订

## 背景与目标

初版 Subscriptions 兼容组件漏打包 cordis.patch.yml，导致 Host 无法启用订阅设置。按维护者授权覆盖同步 v3.4.0 附件，并公开修订原因。

## 修改范围与方案

- scripts/verify-release-compat.mjs 与 tests/release-compat.test.mjs：反查声明入口的存在性及文件清单归属。
- docs/3.4.0-第三方插件与兼容包.md 与 docs/releases/v3.4.0/：修订说明及 transport.2 清单。
- .github/scripts/repair-v3.4.0.py、.github/repair-v3.4.0.json 与配套 workflow：绑定既有 release、产品 tag、前后摘要；先核验暂存替代件，再提升正式附件。
- 兼容总包保留六个组件及原许可证；恢复 overlay，更新合成补丁、校验器和全部摘要。

不新增运行依赖、API、数据库字段或数据迁移。主插件包及产品 tag 保持原字节/身份，附件修订源码另记 main commit。

## 风险与验证

GitHub 单个附件替换期间可能短暂缺少该文件；所有替代件先下载校验，支持同一次运行中断后使用已验证暂存件继续。任何未知前像或 tag 变化均拒绝修改。原 SHA256SUMS 对被修订附件不再适用，使用者必须重新下载。

验证声明入口回归、合成补丁 apply/check/restore、六组件归档闭包、无 node_modules/链接、14 个公开附件下载字节和最终 release 清单。已有真实 Host 与设置页恢复证据不扩大为所有供应商功能保证。

## 回滚

保留原发布附件和摘要；如需回滚附件，重新授权并以精确前后摘要执行反向替换。运行数据和账号不在本次写入范围。
